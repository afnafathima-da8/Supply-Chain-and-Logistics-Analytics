# 📦 Supply Chain & Logistics Analytics

## 📌 Project Overview

This project focuses on analysing supply chain and logistics operations to understand delivery performance, shipping efficiency, regional performance, and order trends.

The objective is to identify delivery delays, evaluate shipping methods, and generate meaningful business insights that can help improve logistics operations and customer satisfaction.

## 🎯 Project Objectives

- Analyse overall order performance.
- Identify late and on-time deliveries.
- Evaluate shipping mode efficiency.
- Identify regions with higher delivery delays.
- Analyse monthly order trends.
- Identify the most frequently ordered products.
- Generate actionable business recommendations.

## 🛠️ Tools & Technologies

- **Python** – Data cleaning and analysis.
- **Pandas & NumPy** – Data manipulation.
- **Matplotlib & Seaborn** – Data visualization.
- **PostgreSQL** – Database management and SQL analysis.
- **Plotly / HTML** – Interactive dashboard.

## 🧹 Data Cleaning & Preparation

The following data preparation steps were performed:

- Checked missing values.
- Checked and removed duplicate records.
- Converted order and shipping dates into datetime format.
- Created a new column to calculate delivery delay.
- Classified deliveries as Late or On Time.
- Extracted month and year information.
- Removed personal customer information from the analysis dataset.
- Prepared a cleaned dataset for SQL analysis.

## 📈 Dashboard Features

The interactive dashboard includes:

1. **Monthly Orders** – Tracks order trends over time.
2. **Delivery Performance** – Compares late and on-time deliveries.
3. **Shipping Mode Analysis** – Compares average delivery delays across shipping methods.
4. **Regional Analysis** – Identifies regions with the highest late-delivery percentages.
5. **Product Analysis** – Displays the top products by order quantity.

## 🔍 Key Business Insights

- More than half of the analysed orders were classified as late deliveries.
- On-time delivery performance needs improvement.
- Shipping methods can be compared to identify opportunities for better logistics efficiency.
- Regional delivery analysis can help identify areas requiring operational attention.
- Product demand analysis can support inventory and supply planning.

## 💡 Business Recommendations

- Improve delivery scheduling and transportation planning.
- Investigate the reasons behind late deliveries.
- Monitor shipping mode performance regularly.
- Focus on regions with high late-delivery percentages.
- Use product demand trends to improve inventory planning.
